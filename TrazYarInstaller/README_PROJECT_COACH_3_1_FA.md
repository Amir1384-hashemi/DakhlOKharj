# تراز یار ۳٫۱ — آموزش پروژه‌محور

- راهنمای انتخاب ابزار با ۶ سناریوی نصب واقعی: ماشین لباس‌شویی، کابینت یا میز چهارپایه، نصب قفسه، قائم‌بودن در یا ستون، بررسی زاویهٔ قائمه، سنجش شیب مسیر
- مراحل شماره‌دار و قابل پیمایش، اطلاعات ایمنی و محدودیت‌های هر ابزار، درصد پیشرفت نمایشی
- دکمهٔ مستقیم رفتن به ابزار مناسب و برگشت به همان گام از راهنمای کار
- ذخیرهٔ محلی پروژه و گام فعلی پس از بستن برنامه
- میان‌بر از صفحهٔ اصلی، مرکز آموزش و نصاب‌یار
- هیچ نیاز به اینترنت یا کتابخانهٔ اضافه ندارد؛ نصاب‌یار از نسخهٔ ۲٫۹ و مرکز آموزش ۳٫۰ بدون تغییر حفظ شده‌اند
- بوق تنها در تراز حبابی فعال است؛ نه نصاب‌یار و نه دیگر ابزارها
- برای ابزارهای مرتبط با کف‌شور یا لوله مقدار «شیب لازم» توسط برنامه انتخاب نمی‌شود؛ کاربر باید استاندارد یا طراحی پروژه را بداند
- این راهنما جایگزین آموزش عملی، رعایت اصول ایمنی یا ابزار کالیبره‌شده نیست

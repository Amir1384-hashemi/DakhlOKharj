# آزمون پیش از نصب تراز یار ۳٫۱
در GitHub Actions ابتدا تمام آزمون‌های میزبان برای ریاضیات تراز/شیب/زاویه/گونیا، الگوی بوق، کالیبراسیون، نصاب‌یار و گزارش، مرکز آموزش و شش پروژه اجرا می‌شوند. سپس APK با Gradle ساخته شده و در شبیه‌ساز Android 11 با API 30 نصب و راه‌اندازی می‌شود. اسکریپت UI باید معرفی برنامه، مرکز آموزش، انتخاب ۶ پروژه، گام‌های قبل/بعد، ورود به نصاب‌یار و چهار ابزار اصلی را روی محیط اندروید تست کند؛ سپس نبود کرش را کنترل کند. APK جدید فقط بعد از عبور تمام آزمون‌ها منتشر می‌شود.
محدودیت: خروجی واقعی صدا، عملکرد دقیق حسگر، چرخش فیزیکی گوشی، ذخیره واقعی با حسگر روی سامسونگ و دقت چهار پایه روی جسم واقعی با این روش تأیید نمی‌شود.

# تراز یار نسخه ۳٫۰ — معرفی و آموزش جامع

- کارت معرفی صریح برنامه در صفحهٔ اصلی (هدف، پنج ابزار و نتایج کار)
- دکمهٔ مستقل «معرفی برنامه و مرکز آموزش کامل» بالای صفحه
- نمایش معرفی یک‌بار برای کاربر تازه‌وارد یا پس از ارتقای نسخه
- بخش اختصاصی و آفلاین با ۱۲ فصل فارسی برای تمامی ابزارهای اندازه‌گیری و نصاب‌یار، کالیبراسیون، بوق، قفل عدد، دفترچه، گزارش و رفع مشکل
- انتخاب مستقیم فصل از فهرست + میان‌برهای واضح زاویه‌سنج، گونیا و نصاب‌یار
- نمودارها و شکل‌های برداری در خود اندروید، بدون شبکه و دانلود فایل
- دکمهٔ مستقیم باز کردن ابزار موضوع فعلی، همراه با راهنمای شماره‌دار و نکتهٔ دقت
- آموزش مستقل نصاب‌یار از داخل صفحهٔ خودش نیز قابل بازکردن است
- دکمه‌های قبلی و بعدی همیشه ثابت در پایین صفحه‌اند
- رفتار بوق از نسخهٔ پیش حفظ شده: صرفاً ابزار تراز حبابی
- APK ساخته‌شده در GitHub Actions با آزمون یکپارچگی متن و مسیرهای راهنما؛ اجرای عملی باید روی گوشی سامسونگ هم تأیید شود

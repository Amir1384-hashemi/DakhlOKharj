# Hamsayeban - working offline Android beta
This is **Hamsayeban**, separate from ModirYar/DakhlOKharj.
Android WebView shell built with Android Gradle Plugin, bundling the original Hamsayeban finance application. On-device persistent data. Finance calculations, multiple buildings, units, charges, payments, partial and surplus payments, expense allocation, cash, refunds, announcements, tickets, polls, and reports are local. Backups and CSV exports open Android's real Save Document dialog.
This is NOT the online multi-device app. Resident mode is a local preview only; no authentication or real-time two-way messages. Data must not be treated as backed up until explicitly exported.
